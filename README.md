## Jak edytować dane na stronie

1. **Zmiana telefonu/emaila:** 
   - Wyszukaj w `index.html`: `500 772 661` lub `biuro@wynajemautolawety.pl`
   - Zastąp nowymi danymi
   - Sprawdź również link `tel:` w nawigacji

2. **Zmiana cennika:**
   - Wyszukaj sekcję `id="pricing"` w `index.html`
   - Zmień wartości w klasach `.price-main`

3. **Zmiana listy miast:**
   - Wyszukaj sekcję `id="branches"` w `index.html`
   - Znajdź select `id="branchSelect"` i `id="res-branch"`
   - Zaktualizuj opcje `<option>`

4. **Zmiana tekstów:**
   - Wyszukaj odpowiednie sekcje w `index.html` według nagłówków powyżej
   - Zastąp teksty nowymi treściami
