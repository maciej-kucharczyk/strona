# Folder na zdjęcia

## Jak dodać zdjęcie autolawety jako tło

1. Umieść swoje zdjęcie autolawety (Opel Movano w zielonym kolorze, podwójna kabina) w tym folderze
2. Nazwij plik: `autolaweta-tlo.jpg` (lub zmień nazwę w pliku `styles.css`)
3. Zalecane wymiary: minimum 1920x1080px
4. Format: JPG, PNG lub WebP

## Wymagania do zdjęcia

- Opel Movano w podwójnej kabinie
- Zielony kolor
- Autolaweta z tyłu (widok z tyłu pojazdu)
- Neutralne tło (np. szare, białe, lub rozmyte)
- Wysoka jakość dla lepszego efektu

## Alternatywa

Jeśli nie masz zdjęcia, możesz:
- Użyć zdjęcia z opisanych przez Ciebie zdjęć
- Zastosować gradient jako tło (już skonfigurowany w CSS)
- Użyć zdjęcia stockowego autolawety

## Zmiana nazwy pliku

Jeśli chcesz użyć innej nazwy pliku, edytuj plik `styles.css` i zmień:
```css
background-image: url('images/autolaweta-tlo.jpg');
```
na:
```css
background-image: url('images/twoja-nazwa-pliku.jpg');
```
